Multimodal RAG Engine — Cross-Modal Document Intelligence

An enterprise‑grade document intelligence system performing joint retrieval of dense text and embedded visual figures from complex PDF reports using dual‑vector search, Reciprocal Rank Fusion, MS‑MARCO Cross‑Encoder reranking, and Claude API Vision‑LLM generation.

Extracts Text & Visuals

Extracts both text and high‑DPI page images from PDFs using PyMuPDF, with sentence‑aware chunking (~300 chars).

Dual‑Vector Retrieval

Creates a dual‑vector index (SentenceTransformer 384‑d text + OpenCLIP 512‑d image) fused via Reciprocal Rank Fusion and refined with MS‑MARCO Cross‑Encoder reranking.

Grounded LLM Answers

Generates answers with Claude Vision‑LLM, enforcing XML‑based prompt defenses and providing precise page citations.

System Architecture

End-to-end processing pipeline: PyMuPDF PDF extraction -> Dual Text (SentenceTransformer) & Visual (OpenCLIP) vector generation -> Reciprocal Rank Fusion & MS-MARCO Reranking in Qdrant -> Grounded XML Generation via Claude Vision-LLM.

Key Implementation Details

  • Sentence-Aware PDF Chunking: Custom PyMuPDF chunker enforcing ~300 character boundaries aligned to sentence terminators, preventing fragmented context.
  • Reciprocal Rank Fusion & Reranking: Fuses rank scores from text embeddings and visual embeddings before applying an MS-MARCO Cross-Encoder, isolating the 3 highest relevance chunks.
  • Hallucination Defense: Claude API prompts wrapped in XML tags enforcing refusal logic when context confidence drops below thresh (≥ 0.40).
  • Backend Optimization: FastAPI server utilizes threadpool background task execution and model pre-warming on startup for immediate query handling.

Results

Achieved high precision cross-modal document retrieval with sub-second vector search performance in Qdrant, cutting retrieved context noise by over 60% while maintaining 100% citation grounding across multi-page technical reports.
